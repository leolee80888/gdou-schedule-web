# 广海课表云 Web 版（GdouSchedule Web）

仿 Android 应用「广海课表云」的**单文件网页课表**：把一个 HTML 文件丢进浏览器就能用，导入教务系统导出的课表 PDF 后自动排成周课表，并区分「本周 / 非本周」。

- 无后端、无外部依赖、无网络请求，所有数据只存在浏览器本地（`localStorage`）
- **纯本地文件**：双击 HTML 用浏览器打开即可使用，本项目不提供在线部署，请下载到本地运行

## 下载

到 [**Releases**](https://github.com/leolee80888/gdou-schedule-web/releases) 下载单个 HTML 文件，双击用浏览器打开即可，不联网也能用：

- `gdou-schedule-web-v1.0.0.html` —— 空白版，打开后导入自己的课表 PDF

也可以直接克隆仓库，用仓库里的 `index.html`（与 Release 里的文件内容一致）。

## 单文件

仓库只有一份可执行文件：

| 文件 | 说明 |
| --- | --- |
| `index.html` | 空白课表：默认没有课程，点右上角「导入」选自己的课表 PDF 即可 |

## 功能

**课表视图**
- 周视图：7 天 × 10 节的完整网格，左列显示节次与上下课时间，今天整列高亮
- 日视图：按「上午 / 下午 / 晚上」分组的课程列表，可前后翻日
- 三种过滤：**本周**（当前教学周该上的课）/ **非本周**（灰块 + 「非本周」标签）/ **全学期**（全部课块）
- 20 周周次条：点击跳周、当前周描边、自动滚动到居中
- 课程色卡：按课程名散列到 12 色糖果板，同课同色；单/双周展示小胶囊

**课程详情**
- 课程名、节次与时间、校区、场地、教师、教学班、学分、考核方式、周学时
- 20 周周次分布点阵，一眼看出这门课哪几周上
- 一键跳转高德地图搜教室

**导入**
- **课表 PDF**：教务系统导出的纯文字版 PDF，自动识别星期列、节次行、周次、教室、教师、教学班、学分
- 粘贴课表文字：`周一 1-2 高等数学 5-16周 钟海楼04021 蒋祖再`
- 粘贴 / 导入 JSON
- 导出当前课表 JSON 备份；「清空课表，恢复空白」可随时重置
- 「解析诊断」面板逐条打印解析过程，导入不准时能直接看到原因

**设置**
- 学期、学生姓名、**第一教学周周一**、总周数
- 10 节课的作息时间可自定义、可恢复默认
- 课前提醒分钟数

## 使用方法

1. 把 `index.html`（或 Releases 里的 HTML）下载到本地，双击用浏览器打开
2. 到教务系统导出「课表」PDF（导出时勾选包含课表详情，确保是文字版而不是截图）
3. 点「导入」→ 选择 PDF → 等待解析完成
4. 到「设置」核对**第一教学周周一**（默认 `2026-08-31`，2026-2027-1 学期适用），否则本周/非本周会算错
5. 数据会自动保存在浏览器里，换浏览器或用无痕模式不会保留，可用「导出当前课表 JSON」备份

## PDF 解析是怎么做的

全部在浏览器里用原生 JS 手写实现（不依赖 pdf.js）：

1. **拆对象**：扫描 PDF 的间接对象，找出所有 `/Filter /FlateDecode` 的内容流和字体流
2. **解压**：`DecompressionStream("deflate")` 解 zlib，得到内容流原文
3. **取文字**：按 PDF 内容流语法 token 化，跟踪 `BT / Tm / Td / TD / TL / T* / Tf` 得到每段文字的坐标，`Tj / TJ / ' / "` 取字符串；中文一般是 UTF-16BE（有 `/ToUnicode` 时按 CMap 映射）
4. **认表头**：找出 `星期一…星期日` 这一行，以它们的 x 坐标作为 7 列的列心；缺列时按列距外推
5. **切课块**：按列归类后，按 y 从大到小扫，遇到 `(1-2节)` 这类标记就开一个新课块，其余行按「字段行 / 课程名行」归并
6. **拼折行**：PDF 会把单元格文字按固定宽度硬折行（每行约 18 字），拼接时中文之间不加空格、英文之间补空格；课程名自身的折行（如「大学生职业发展与就业」+「指导」）也一并合上
7. **取字段**：从拼好的文本里按 `校区: / 场地: / 教师: / 教学班: / 考核方式: / 周学时: / 学分:` 抽值，去掉导出器附加的 `*` `$` `x1` 之类的标记
8. **展开周次**：`9-16周`、`5-7周(单),8-16周`、`第8周`、`10-12周(双),13周` 都展开成周次集合；同一时段同一门课的多段周次自动并集

## 已知限制

- 只支持**文字版** PDF；扫描件 / 图片版 PDF 无法提取文字，会提示改用粘贴文字
- 各校教务系统导出的 PDF 版式差异很大，目前主要针对「广东海洋大学（广海）教务导出格式」验证；其他版式可能在列定位或课块切分上出偏差，可用「解析诊断」查看原因
- 一周超过 10 节的课表需要改作息（当前默认 10 节）
- 数据存在浏览器 `localStorage`：清理浏览器数据、换浏览器、换设备都会丢，请用 JSON 导出备份
